# 仪表投屏 v2.2.1 发行说明

> 车机端 APK：`com.xiaopeng.vdcast`（「仪表投屏」），Android 12 / 2400×1200。
> 这一版只修一个问题：**车机 2/3 窗口切到左栏时，投屏画面错位/黑屏**。
> 其余功能与 v2.2 一致。

## 一、修了什么

小鹏的 2/3 窗口可以左右切换：右栏 `[960,0][2400,1080]`，左栏 `[120,0][1560,1080]`
（宽都是 1440，原点差 840）。旧版把两件事写死成右栏：

1. 发送端只认右栏，启动/还原都把窗口往 `x=960` 摆；
2. 裁切 `960,345,1440,426` 是车机屏幕绝对坐标，窗口切到左栏后仍然抓 `x=960..2400`，
   右半截是空桌面 —— 仪表上就是错位或黑屏。

v2.2.1 改为**跟随窗口实际所在的 2/3 栏**：

- 启动时识别窗口落在左栏还是右栏（`paneOf()` 两种原点都认），把裁切整体平移到那一栏；
- 运行中每 5 秒复查一次，手动把窗口拖到另一侧，**5 秒内**裁切跟着走；
- 停止时还原到**投屏前**所在的栏位：左栏进就左栏出，右栏进就右栏出（旧版一律回右栏）；
- 框选时窗口的 bounds 记在 `/data/local/tmp/vdcrop.base` 当平移基准；没有基准文件时，
  只对 1200..1700 宽的 2/3 栏裁切按 x 推断。全屏框选（≈2400×1200）、1/3 栏、
  1920 宽的自定义横带都**不平移**，避免越修越偏；
- 全新用户默认裁切 `960,345,1440,426` 在左栏也会自动推断成 `120,345`，不用手改。

## 二、实车验证（8295 / 2400×1200）

测试时面板与 QQ 音乐都在左 2/3 栏。

| 项目 | 结果 |
|---|---|
| 左栏启动投屏 | 日志 `pane follow 120,0 (left)`、`crop follow pane ... -> 120,26`；仪表 730×523 画面正常，61 fps |
| 运行中换到右栏 | `am task resize` 后约 5 秒，日志 `crop follow pane 960,0 ... -> 960,26` |
| 停止 | 窗口回到投屏前的 `[120,0][1560,1080]`，`vdorig.txt` 自动清理 |
| 右栏启动/停止 | 同样跟随与还原（右栏进右栏出） |
| 预览页 | 1920×720 仪表原版面 + 投屏区，画面正确 |
| 默认裁切推断 | 无 base 文件时 `960,345` → `120,345`，cropForOut 按仪表比例扩为 1440×1032 |

## 三、安装

本 ROM 对非平台签名的 APK **拒绝 `adb install` / `pm install`**（`isPlatSigned:false`），
只能走图形安装器：

```bash
bash tools/installapk.sh adbprobe/AdbProbe.apk com.xiaopeng.vdcast vdcast.apk
```

脚本会自动：push → 调起安装器 → 轮询前台 → 两次回车/右移确认 → 用 `lastUpdateTime`
校验是否真的装上。**升级请用覆盖安装**（省掉重新授权一次）。

## 四、已知限制

- 只支持 **2/3 栏**的左右跟随；1/3 栏（宽约 826）与全屏不做平移。
- 运行中换边依赖 5 秒轮询，最长有 5 秒的旧画面。
- 面板「应用」裁切时，若窗口当前所在栏与裁切框不在同一栏，会以框选时的窗口为基准平移
  （几何上一致，但看到的可能仍是空桌面）——重新「框选」一次即可。
- 保活（后台 30 分钟不被杀）仍未验证（与 v2.2 同）。
