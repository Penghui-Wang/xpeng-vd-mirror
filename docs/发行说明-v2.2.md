# 仪表投屏 v2.2 发行说明

> 车机端 APK：`com.xiaopeng.vdcast`（「仪表投屏」），Android 12 / 2400×1200。
> 这一版把 B0–B5 五批改造全部收口：面板可退出、遥控入口统一、选应用/裁切/预览重做、启动与停止提速。

## 一、这一版能做什么

- **一键启动/停止**：面板只剩一个主 CTA；停止走完整收尾（停发送端 → 停接收端 → 确认仪表恢复 → 清临时文件），
  成功判据只认 `RESTORE_OK / pixels restored / RESTORED blank`，不干净会明确报出来。
- **三层小灯**：ADB / 发送端 / 接收端 + 两侧帧率，能分开「adb 断了」「发送端死了」「接收端没起」。
- **选应用**：5 列图标网格 + 名称 + 运行中角标 + 搜索（不再是一列包名对话框）。
- **仪表区域 / 车机裁切 / 预览**：
  - 裁切页左上角标明底图来源（虚拟屏 / 目标应用窗口 / 主屏）；
  - 锁比例直接按「仪表区域」算，先定矩形、没启动就框选也不变形；
  - 预览是「仪表原版面 + 投屏区」的合成图，一眼看出有没有压到车速/告警带；
  - **没投屏也能静态预演**（截一张合成，不碰发送端）。
- **安全件约束**：默认投屏区 `352,180,1216,360`（43.8 万像素，四周留白，不覆盖整个仪表）；
  手填/框选全屏仍然允许，但面板会给两行 ⚠ 提示。**面板与日志不承诺帧率**。
- **遥控入口**：22 个动作统一（`act=help` 可打印整表），PC 侧配 `tools/vdcast.sh`，参数顺序由脚本保证。
- **不代关应用**：退出只停自己的进程，目标应用（比如正在放的音乐）不会被一起关掉。

## 二、这一版的实测数字

| 指标 | 改前 | v2.2 |
|---|---|---|
| 启动到「就绪」 | 5.15 s | **2.93 s** |
| 停止到「收尾完成」 | 4.95 s | **1.69 s** |
| 换应用重启 | 会留全屏残窗 | 无残窗（约 4.27 s） |
| 预览首帧 | 无埋点 | 114 ms（静态）/ 81 ms（实时） |

仪表端帧率：默认安全区实测约 31–46 fps（受画面复杂度影响，**不作承诺、也不是验收条件**）。

## 三、安装

本 ROM 对非平台签名的 APK **拒绝 `adb install` / `pm install`**（`isPlatSigned:false`），只能走图形安装器：

```bash
# 车机已连 adb（192.168.31.210:5050）时
bash tools/installapk.sh adbprobe/AdbProbe.apk com.xiaopeng.vdcast vdcast.apk
```

脚本会自动：push → 调起安装器 → 轮询前台 → 两次回车/右移确认 → 用 `lastUpdateTime` 校验是否真的装上。
**升级请用覆盖安装**（省掉重新授权一次）。

首次连接需要一次 adb 授权；如果卡住，去 开发者工具 → 无线 ADB 关掉再打开 复位，然后重连。

## 四、已知限制

- **必须驻车**才能起投屏；仪表是安全件，默认不铺满。
- **接收端二进制**首次启动会推到仪表（约 10–30 s，一次性）；之后走缓存。
- **换 APK 后第一次启动**会重推 dex/接收端，比稳态慢一些。
- 保活（后台 30 分钟不被杀）**未验证**（UX-14 暂缓），不要当成卖点。
- 个别系统自带应用在「选应用」里会被过滤（label 就是包名的内部 activity），这是有意的。
